# Norsk Økonomi – Komplett forskningspakke 2026

Start nettsiden i `nettside/index.html`. Nettsiden er et statisk HTML-dokument, uten avhengighet av ekstern JavaScript. Ved publisering bør hele mappestrukturen lastes opp uendret.

- `Norsk_Okonomi_Samlet_Forskningsrapport_2026_v2.md`: Samlet originalinnhold og redaksjonell innledning.
- `VITENSKAPELIG_KVALITETSSIKRING.md`: Kontrollstatus og åpne forskningsoppgaver.
- `grunnmateriale_01-09/`: Uendret innhold fra original ZIP, inkludert datagrunnlag, kode, historiske rapportversjoner og 01–09.
- `delrapporter_10-12/`: Markdown og HTML for delrapporter 10–12.
- `MANIFEST_SHA256.json`: Filregister og SHA-256 for pakkens øvrige filer.

**Viktig:** Dokumentene er forskningsutkast, ikke eksternt fagfellevurdert. Maskinell registerkontroll er gjennomført, men full metodisk og empirisk replikasjon gjenstår.
