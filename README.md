# Norsk Økonomi – Interaktiv forskningsportal v3.0

Last opp alle filene i denne mappen til webserveren. Åpne index.html. Ingen installasjon eller ekstern JavaScript-tjeneste nødvendig. Historiske simulatorer er forenklede scenarioer og ikke prognoser. Full forskningstekst gjengis i nettsiden. Versjon 13.10.2026.


## Innhold i release v3.0
Avsluttende konklusjon er lagt til som siste kapittel i Markdown og nettside. Interaktive datasett og modeller er beholdt. Normativ vurdering er merket separat fra kausale funn.
